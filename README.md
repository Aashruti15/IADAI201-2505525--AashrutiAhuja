# Overview

ParkVision AI is an intelligent parking analytics system that uses a custom YOLOv8 object detection model to identify occupied and empty parking slots from a single image. A user uploads a photo of a parking lot, and the system detects every visible slot, marks it as occupied (red) or empty (green), and generates real-time occupancy insights — including total slots, availability, occupancy percentage, congestion level, and a plain-language recommendation.

Input: An image of a parking lot (aerial/elevated surveillance-style view)
Output: Slot-wise occupancy status, summary statistics, and a recommendation
Real-world challenges considered: varying weather/lighting (sunny, cloudy, rainy), partial occlusion of vehicles, and differences in camera angle between training data and real-world images


# Features
1. Upload any parking lot image directly in the browser
2. Automatic slot detection with color-coded bounding boxes (green = empty, red = occupied)
3. Live summary panel: total slots, occupied slots, available slots, occupancy %
4. Congestion level classification: Low (<40%), Moderate (40-75%), High (>75%)
5. Plain-language recommendation based on current occupancy
6. Visual charts: slot breakdown bar chart and occupancy gauge
7. Downloadable annotated result image
8. Sidebar with usage instructions, model details, and congestion scale legend


# Accuracy

Model: YOLOv8n (Nano), fine-tuned via transfer learning on a PKLot subset (400 train / 100 validation / 60 test images), 20 epochs, image size 416.

Class	Precision	Recall	mAP50	mAP50-95

space-empty	93.5%	92.4%	95.4%	69.7%

space-occupied	95.1%	98.1%	98.5%	68.2%

All classes	94.3%	95.2%	96.9%	68.9%

# Stakeholders
1. Drivers / commuters — get quick, reliable visibility into slot availability before arriving at a lot, saving time spent circling for parking.
2. Parking lot operators / facility managers — can monitor occupancy trends and congestion levels without manual counting or expensive sensor hardware.
3. City/urban planning bodies — aggregated occupancy data can inform decisions on parking capacity, signage, and traffic flow around busy areas.
4. Developers/students (project stakeholders) — a practical demonstration of applying object detection to a real infrastructure problem, usable as a portfolio project or foundation for further development.


# Testing & Feedback

The model was tested in two conditions:

1. Held-out PKLot test images (same distribution as training data) — performed reliably, closely matching the validation metrics above.
An out-of-distribution stock photo (different camera angle, lighting, and car density than PKLot) — the model showed reduced recall, missing some occupied/empty slots and occasionally misclassifying an occupied slot as empty.

2. Feedback / observation: This gap highlights a generalization limitation — the model is closely tuned to PKLot's specific camera angles and lighting conditions, and accuracy drops on unfamiliar real-world images. This is a common and expected finding for models trained on a single, narrow dataset.

3. Suggested improvement: training on a larger, more diverse dataset spanning multiple camera angles, lot types, and lighting conditions would likely close this gap and improve real-world robustness.


# Conclusion

ParkVision AI demonstrates that a lightweight YOLOv8 model, fine-tuned on a relatively small subset of labeled data, can achieve strong accuracy (~97% mAP50) at detecting parking slot occupancy from images. The system translates raw detections into clear, actionable insights through a simple web interface, making it usable by non-technical stakeholders such as drivers or lot managers. While the model performs very well on data similar to its training set, testing on an unfamiliar image revealed a real-world generalization gap — a valuable insight for future iterations. With a more diverse training dataset, this approach could scale into a genuinely useful tool for smart parking management.
